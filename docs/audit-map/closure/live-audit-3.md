Среда: Expo web localhost:8081, backend 127.0.0.1:8100, проект «AUDIT3 Квартира» (свой, адрес «E2E audit3»). После прогона проект уходит в корзину/архив. Скриншоты вне репозитория (scratchpad).

## Исправлено

### A3-01 (P2, исправлено) Сырые ISO-даты и суммы в нескольких местах
- Исполнитель: «Ремонт → Этапы» и «Гарантия» — строка этапа `— · 2026-10-06 · 5 542 ₽`; карточка этапа «План: 2026-10-03 → 2026-10-06» и «Срок доработки»; Приёмка («Срок доработки: …»); Контроль («до 2026-…»); Портал («План окончания»). Теперь `дд.мм.гггг` (`formatScheduleDayFull`).
- Лента активности: «2026-10-03 20:32» (UTC без пояса) → местное «03.10.2026 23:32» (`formatEventDateTime`).
- Чат, карточка задачи: «Задача: … · до 2026-10-05» → «до 05.10.2026» (backend `chat_service._ru_date`).
- Уведомления: тело «15000.0» («Доп. работы согласованы») → «15 000 ₽»; нормализация при записи и чтении (`normalize_notification_body`), для ленты активности добавлен вид `ChangeOrder*`.
- Активность «Создан объект»: «план: 110848.80 ₽» → «110 848,80 ₽».
- Тесты: `backend/tests/test_money_format.py` (2 новых), `apps/mobile/lib/auditThree.test.ts` (в `mobile:test`).
