## Гость (viewer) и портал
- Viewer по проекту (read-only, `access_mode=guest`): GET проекта/платежей/расходов/сметы/документов/календаря/активности/бюджета читаются (200), все записи — 403 (`comment`, `payment`, `start stage`, `chat create`; подпись → 404). `portal-links` для гостя 403. `customer_budget` скрыт.
- Чаты: гость видит только тред общей темы, при этом `messages` пуст, писать нельзя (`communication_forbidden`); тред «payment» ему закрыт (403 на чтение/запись и нет в списке). Сообщения-счета в общем чате гостю не отдаются.
- Портал (magic link, scope `read`): снапшот с суммами сметы/счетов, «Оплата недоступна в режиме просмотра», 375/1280 без горизонтального скролла. Отзыв ссылки заказчиком → `/auth/portal/session` 401 и старый access-токен на снапшот 401; исполнитель может отозвать только свою ссылку (чужая 404/403), выпустить `allow_pay` не может (403 `portal_write_scopes_customer_only`).
- P2/P3 в UI гостя: на главной гостя — CTA «Оплатить 2 счета / Посмотреть · Оплатить» при режиме «только просмотр» (кнопка ведёт на список, но формулировка зовёт оплатить); на вкладке «Приёмка» остаётся текст «Примите этап или верните на доработку…»; «Оплаты» — текст для заказчика («приложите чек…»); в профиле гостя доступны «Новый проект» и «Удалить аккаунт» (гость в демо — полноправный пользователь, создание проекта API разрешает).
