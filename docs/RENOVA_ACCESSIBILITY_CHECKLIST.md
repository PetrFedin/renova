# Renova Accessibility Checklist

## Interaction

- Touch targets should be comfortable on mobile.
- Actions should have clear labels.
- Destructive operations should communicate consequences.

## Typography

- Hierarchy should be readable without relying only on color.
- Important information should remain visible in different states.
- Text contrast should support long usage.

## Navigation

- Current location should be understandable.
- Important actions should not depend on hidden gestures.
- Empty and error states should provide direction.

## Components

Review:

- buttons;
- sheets;
- chips;
- forms;
- lists.

All shared components should maintain predictable behavior.

## Product principle

Accessibility improvements improve the experience for every user by making the interface clearer and more predictable.
