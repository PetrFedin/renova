# Renova Polish Phase 1

## Goal
Elevate Clarity A-W from functional consistency to premium product polish.

## Current focus

### CTA and interaction consistency

- destructive actions use danger hierarchy
- confirm flows use ActionConfirmSheet
- primary actions remain singular per surface
- secondary actions use outline treatment
- touch targets follow minimum interaction size

## Implementation order

### P1. Money surfaces

- ExpenseDetailSheet action hierarchy
- PaymentDetailSheet CTA simplification
- Budget actions consistency
- destructive money operations visibility

### P2. Operational hubs

- Budget Summary: summary first, details second
- Rooms: list as overview, editing in detail
- Materials: remove duplicate chrome and duplicate actions

### P3. Platform consistency

- Portal actions match in-app components
- Sheets share common chrome
- Forms use common labels and controls
- Filters use one chip language

### Quality gates

- no destructive action visually equal to secondary action
- no primary CTA duplication in one viewport
- no touch target below mobile ergonomics baseline
- no unnecessary card stacking where list density is better

## Next implementation blocks

1. Budget Summary simplification.
2. Rooms list/detail separation.
3. Materials procurement surface cleanup.
4. Portal visual parity.
5. Motion and interaction polish.
