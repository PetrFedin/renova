## Как читать новые файлы (04-08)

1. Начните с `04` раздел 1 (карта) и раздел 8 (что сломано или не связано); реестр действий (раздел 2) используйте как справочник: ID строки сквозные (A, H, O, R, B, C, D, S, X).
2. Для денег и «Верно» читать `08` вместе с `06` (цифры) и `07` (юридические и производственные ворота).
3. `ui-kit.html` открывать в браузере из папки пакета; в репозиторий приложения не копировать без решения владельца (мандат §1.5).
4. Везде: числа и рыночные факты помечены как гипотезы; веб-источники конкурентов датированы 2026-10-15; перепись `docs/audit-map/09-screen-census-routes.md` (срез 2026-09-30) используется как вход и помечена `[перепись]`.

## Как использовать

1. Начните с резюме в `01-business-plan.md` (раздел 1) и раздела 14 «Что показать инвестору».
2. Любое инженерное решение сверяйте с `AGENTS.md` репозитория: он приоритетнее этого пакета. Рекомендации здесь не отменяют правил проекта.
3. Числа финансовой модели (раздел 8) пересчитывайте под свои допущения: формулы приведены. Это не прогноз.
4. `DESIGN.md` описывает то, что уже есть в `apps/mobile/constants/Theme.ts`. При расхождении прав `Theme.ts`.
5. Статусы по доказательствам используйте как в проекте: IMPLEMENTED / TESTED / CI VERIFIED / STAGING VERIFIED / EXTERNALLY VERIFIED / PRODUCTION VERIFIED.
