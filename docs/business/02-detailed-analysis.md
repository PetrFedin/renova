# Renova: детальный разбор

Дата: 2026-10-15. Метод: чтение файлов и `git ls-files` / `git log` / `git status`; ничего не запускалось. Статусы доказательств как в `AGENTS.md` §1.

## 1. Архитектура

```
Mobile (Expo/RN, expo-router)
  -> API (FastAPI): auth/OTP, ACL проекта, синхронные операции
  -> PostgreSQL: авторитетное состояние
  -> одна транзакция: мутация + audit + DomainOutbox
  -> renova-worker: claim, вызов провайдера, retry/backoff, DLQ
  -> провайдеры: ЮKassa, ФНС, Twilio, push, e-sign, S3
  -> сверка / health / восстановление оператором
```

Источники: `README.md` (Runtime architecture), `AGENTS.md` §2-5.

| Слой | Размер/факт | Где |

| Мобильное | 1099 TS/TSX-файлов в `apps/mobile`; 383 `.tsx` в `app` и `components`; 153 файла `components/renova`, 8 в `components/ui` | `apps/mobile` |

- Двойная реализация расчётов (TS и Python) с эталонами `packages/calc-engine/reference-cases.json`; GP1 требует равенства до 0,01 ₽.

### 2.4. Остаточные риски по расчётам

- `work_market_rates.py` и `market_regions.py`: статические ставки «Москва» и индексы; источник и дата не указаны. Шаблоны `templates.ts` содержат зашитые цены (например, покраска 320, ламинат 450, плитка 1200 ₽/м2) и существуют только для `cosmetic` и `bathroom`; для типов `capital` и `kitchen` по умолчанию используется `cosmetic` (`generateTemplateLines`, ветка `default`). - Деньги в backend: `Decimal` квантование при записи (`CALCULATION-REGISTRY.md` §2); оговорено, что хранилище float-совместимо и крайние суммы требуют проверок.
- В `subscription.py` у checkout есть ветка `demo` (`demo_allowed`); мандат §1.5 требует заменить её симуляторами, не расширять.

## 6. Что нельзя ломать (инварианты из AGENTS.md)

| Инвариант | Суть | Нарушение |
|---|---|---|
| Ветвление | Только `main` → короткая ветка → PR → CI → merge; агенты не мержат | Прямой push, work from `develop` |
| Транзакция | Мутация + audit + DomainOutbox в одной транзакции | Побочный эффект вне транзакции |
| Outbox | Детерминированная постановка, lease, stale-lease rescue, fencing, bounded retries, DLQ с аудитом | Долгие задачи в API-процессе |
| Провайдеры | Нет локального успеха до безопасной сверки; идемпотентность и reconciliation | Успех в UI до подтверждения |
| Финансы | Estimate / Commitment / Purchase / Expense / Payment / Receipt / Refund / Change Order не смешивать; нет `max(receipt, expense, estimate)`; одна экономическая операция не увеличивает расход дважды | Новая эвристика дедупликации |
| Безопасность | Fail-closed ACL, негативные тесты (IDOR, WebSocket, админ, webhooks, удаление аккаунта), без логирования секретов | Ослабление CodeQL/gitleaks ради зелёного PR |
| Alembic | Один head, нет `create_all` в staging/prod, нет проглоченных ошибок, история не переписывается | Миграция `|| true` |
| Навигация | `routeRegistry.ts` источник; Dock = Главная, Сообщения, Объект, Ремонт, Бюджет; приёмка через Ремонт; финансы через Бюджет | Новый верхнеуровневый hub |
| UI | Токены, `components/ui`, один primary CTA, StatusPill, без dev-текста | Локальные стили |
| Ошибки | Различать validation / authz / not found / conflict / dependency / pending / rejected / retryable / terminal | Сырые стеки пользователю |
| Release identity | SHA, immutable tag, digest, mobile build | `latest`, «VERIFIED» без evidence |
| Definition of Done | Полная цепочка, authz, идемпотентность, транзакция, конкурентность, audit, UX состояний, тесты, миграции, синхронизация живой спецификации, evidence | «Код есть» |
| Мандат | Не удалять без доказательства (grep, замена, тест), не уменьшать число прошедших тестов, один PR одна задача, без новых workflow и новых docs вне `technical-spec`/`archive` | См. §1.1-1.5 мандата |
| Запрещённая реанимация | develop-first, v1.1/v1.2 tab maps, demo/header auth в production, API-owned durable jobs, дубль источников денег, `latest` | §13 AGENTS.md |

Каждое изменение документа в этом пакете, которое попадёт в репозиторий, обязано синхронизироваться с живой спецификацией, если оно «governed» (AGENTS.md §1).
