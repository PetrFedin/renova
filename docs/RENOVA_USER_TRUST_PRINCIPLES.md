# Renova User Trust Principles

## Goal

Make every important action understandable and reliable.

## Trust signals

Users should always understand:

- current system state;
- who owns the next action;
- what will happen after confirmation;
- whether the operation was completed.

## Important actions

For financial, approval and destructive actions:

- explain consequences;
- request confirmation when needed;
- provide visible completion state.

## Status communication

Statuses should be:

- clear;
- consistent;
- connected to possible actions.

Avoid:

- ambiguous labels;
- hidden changes;
- silent failures.

## Collaboration

For multi-user workflows:

- ownership should be visible;
- history should be understandable;
- decisions should be traceable.

## Principle

A professional operating system earns trust by making every state and transition predictable.
