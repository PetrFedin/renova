# Renova Content Hierarchy Rules

## Goal

Keep every screen focused on the user's decision.

## Information order

1. Current state

Show what is happening now.

2. Decision

Show what the user can do next.

3. Context

Show supporting information.

4. Details

Show deep data only when needed.

## Avoid

- equal visual weight for all information;
- long KPI stacks before the main decision;
- technical details before user intent;
- duplicated summaries.

## Lists

Operational lists should prioritize:

- status;
- ownership;
- next action;
- progress.

## Detail screens

Detail screens should answer:

- what is this;
- what changed;
- what requires attention;
- what can be done next.

## Principle

Information is valuable only when it improves understanding or action.
