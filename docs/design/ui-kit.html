Что это

Живой кит на токенах apps/mobile/constants/Theme.ts (RenovaTheme), типографике typography.ts, uiTokens.ts и компонентах components/ui, components/renova/PrimaryButton.tsx. Это HTML-копия вида, а не код приложения: при расхождении права Theme.ts и компоненты React Native. Светлая тема единственная: тёмной палитры в Theme.ts нет и здесь она не придумывается (раздел «Тема»). Все цвета ниже заданы переменными; локальных hex в разметке нет, кроме блока токенов в начале файла.

Три вещи, которые кит исправляет относительно канонаТокен borderStrong для границы поля (предложение, 3:1), подпись нижней панели берётся из textMuted вместо tabInactive, вторичный текст на surfaceMuted и accentMuted берётся из neutralText. Первый новый, два других переиспользуют существующие токены. Подробности и расчёт в разделе «Контраст».

Палитра и роли

Роли по канону: primary главная кнопка (одна на экран); accent ссылки и активная вкладка; success / warning / danger / info статусы (фон, граница, текст); цвет не единственный носитель смысла: рядом слово.

Предложение (нет в Theme.ts)

Пунктирная рамка = предложение. textMutedStrong и исправленный tabInactive не требуют новых цветов: они указывают на уже существующие токены neutralText и textMuted.

Автоматическая таблица контраста (WCAG 2.x)

Считается скриптом на странице по значениям переменных (формула относительной яркости, (L1+0.05)/(L2+0.05)). Пороги: 4.5 для обычного текста, 3.0 для крупного текста (от 18.66 px жирного или 24 px) и для нетекстовых элементов (границы полей, иконки).

Тема: светлая и рекомендация

Факт. В Theme.ts только светлая палитра. Но app.json задаёт userInterfaceStyle: "automatic", а Themed.tsx читает остаточную палитру шаблона Expo (Colors.dark), и web-страница +html.tsx при тёмной системной схеме красит фон в локальный цвет. В итоге на устройстве с тёмной темой получится смесь светлых токенов и фрагментов из шаблона. В ките это не показывается: тёмных значений нет в источнике истины.

Рекомендация (решение владельца, не код).

  1. Сначала: зафиксировать светлую тему (userInterfaceStyle: "light") и убрать тёмный фон из +html.tsx. Риск малый; проверка: запуск на устройстве в системной тёмной теме.
  2. Когда понадобится тёмная: ввести палитру в Theme.ts парами «светлая/тёмная» для каждой роли токена, прогнать матрицу контраста обеих тем этим скриптом, только потом менять компоненты. Не вводить локальные тёмные цвета.
  3. До этого не добавлять переключатель темы в интерфейс.

Режим уменьшения движения: анимации кита (спиннер, переходы) отключаются по prefers-reduced-motion; для приложения проверка Reduce Motion не подтверждена (см. пакет 03).
