# Renova Design Review Process

## Purpose

Create a repeatable review process for UI quality as Renova grows.

## Review stages

### 1. Surface review

Check:
- hierarchy;
- spacing;
- visual noise;
- action clarity.

### 2. Interaction review

Check:
- tap behavior;
- confirmations;
- loading;
- recovery paths.

### 3. Consistency review

Check:
- shared components;
- repeated patterns;
- platform language.

### 4. Product review

Check:
- does the screen help make a decision;
- does it reduce uncertainty;
- does it communicate system state.

## Review outcome

Each reviewed surface receives:

- findings;
- priority;
- expected impact;
- implementation status.

## Principle

Do not add UI complexity without improving user understanding or control.
