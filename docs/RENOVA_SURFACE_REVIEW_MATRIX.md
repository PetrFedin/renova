# Renova Surface Review Matrix

## Purpose

Reference matrix for reviewing product surfaces during the polish stage.

## Sheets

Check:
- consistent chrome;
- clear title hierarchy;
- one dominant action;
- safe destructive handling;
- comfortable dismissal.

## Forms

Check:
- labels before inputs;
- predictable field grouping;
- consistent chips;
- clear validation states.

## Portal

Check:
- same component language as app;
- same button hierarchy;
- same confirmation patterns;
- no admin-style density.

## Settings

Check:
- avoid card-per-toggle layouts;
- prioritize scanability;
- keep controls understandable.

## Portfolio

Check:
- reduce repeated containers;
- improve comparison hierarchy;
- keep selection actions obvious.

## Review question

Can a new user understand the current state and next action without exploring multiple competing blocks?
