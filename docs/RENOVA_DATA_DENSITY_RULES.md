# Renova Data Density Rules

## Goal

Balance operational detail with calm interface behavior.

## Density principles

- Show the information needed for the current decision.
- Do not expose all available data at once.
- Prefer progressive disclosure for complex objects.

## Summary surfaces

Summary should contain:

- current status;
- important metric;
- next action;
- key warning if needed.

## Operational lists

Lists should optimize for scanning:

- clear primary label;
- status visibility;
- ownership;
- action availability.

## Dashboards

Avoid:

- many equal KPI cards;
- repeated summaries;
- visual competition between metrics.

Prefer:

- one dominant insight;
- supporting metrics;
- drill-down paths.

## Principle

A professional interface is not the one that shows the most data. It is the one that helps users make better decisions with less effort.
