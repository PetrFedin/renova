# Renova Navigation and Wayfinding Rules

## Goal

Keep users oriented while managing complex renovation workflows.

## Navigation principles

- Core areas should remain predictable.
- The user should always understand where they are.
- Important destinations should not depend on memory.

## Active state

Active navigation should communicate:

- current location;
- available scope;
- relationship between sections.

## Deep workflows

For complex processes:

- show the current step;
- preserve context;
- provide a clear return path.

## Avoid

- hidden critical actions;
- multiple navigation patterns for similar tasks;
- unexplained changes in available sections.

## Principle

Good navigation reduces cognitive load by making the system structure visible.
