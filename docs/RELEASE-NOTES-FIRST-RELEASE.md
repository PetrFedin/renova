# Renova — заметки к первому релизу (черновик кандидата)

Номер версии и дата публикации назначаются владельцем продукта. Исходники несут `0.3.7`. Документ черновой: он описывает то, что подтверждено в коде на 2026-10-01, и честно отделяет работающее от недоступного до внешних подключений. Тексты для стора — отдельная работа с юристом (`PRODUCTION-READINESS.md`, E5/E12).

## Для кого

Заказчики ремонта, исполнители (подрядчики и бригады), технадзор, наблюдатели по ссылке. Язык интерфейса — русский.

## Что можно делать

1. **Вход** по номеру телефона и коду из SMS; роли заказчика и исполнителя.
2. **Объект:** создание проекта с комнатами, приглашение исполнителя. Исполнитель подаёт заявку, заказчик подтверждает; чужой исполнитель доступа не получает.
3. **Смета:** исполнитель ведёт строки, предлагает фиксацию, заказчик принимает или отклоняет с причиной; после фиксации смета неизменна, допработы идут отдельным согласованием.
4. **Договор:** формируется из сметы; этапы нельзя начать, пока его не подписали обе стороны (подпись в приложении).
5. **График и этапы:** согласование графика, запуск этапа, чек-лист, фото результата, сдача и приёмка заказчиком с возвратом на доработку.
6. **Платежи:** счёт по принятому этапу, подтверждение оплаты заказчиком с отметкой о переводе, спор по платежу, подтверждение с чеком; оплата этапа до приёмки не проходит.
7. **Чат и уведомления:** чаты по проекту, вложения, центр уведомлений, push.
8. **Закупки и материалы, допработы, закрытие объекта, гарантийные обращения, корзина и удаление проекта.**
9. **Портал по ссылке** для просмотра и подписи документов; **гость-наблюдатель** только читает.

## Что пока недоступно или выключено

Эти возможности зависят от внешних подключений, которых ещё нет, и в релизе будут выключены или отвечать честной ошибкой, а не имитировать успех:

- Онлайн-оплата через ЮKassa без боевых реквизитов (checkout ответит 503).
- Привязка «Мой налог» и проверка статуса НПД без реквизитов ФНС.
- Внешняя подпись Контур, Госключ (не реализован).
- Push-уведомления до получения ключей APNs/FCM и привязки проекта EAS.
- Распознавание содержимого документов (работает только классификация по метаданным).

## Известные ограничения

- В очереди офлайн-операций повтор после потерянного ответа может задвоить часть действий (#316).
- Нет отчётов о падениях мобильного клиента (не подключён Sentry в клиенте).
- Исправление клиента требует новой сборки и ревью стора (OTA не настроено).
- Полный сценарий независимого подрядчика не завершён.

## Проверка перед установкой (для внутренних тестировщиков)

`python3 scripts/release-smoke.py` против API: проверяет живость, защиту доступа и чтение. Полный сквозной путь (`--write`) — только на одноразовой среде.
