# Renova Visual Audit Backlog

## Phase 1 — Premium polish

## Priority H

### CTA hierarchy

- Verify every destructive action uses danger treatment.
- Keep one primary action per viewport.
- Remove cases where secondary actions compete with business actions.

### Surface consistency

- Align sheets to one chrome system.
- Avoid nested cards inside sheets.
- Prefer list density for operational information.

### Money flows

- Expense actions: save / delete / close hierarchy.
- Payment actions: primary action first, metadata secondary.
- Budget views: decision summary before details.

## Priority M

### Forms

- Unified field labels.
- Consistent chip controls.
- Minimum touch targets.

### Navigation

- Stable dock behavior.
- Clear active states.
- Reduce visual noise from settings.

### Portfolio and documents

- Reduce repeated card containers.
- Improve scanning hierarchy.

## Validation rules

1. User understands next action in 3 seconds.
2. Destructive action is visually distinct.
3. Information density is intentional.
4. Similar objects behave and look the same.
5. Investor walkthrough has no distracting UI debt.
