# Renova Investor Walkthrough QA

## First impression

Verify:
- value is clear in first screen;
- next action is obvious;
- no competing primary messages.

## Navigation

Verify:
- core areas are predictable;
- active state is clear;
- user does not need to remember hidden paths.

## Operational flows

Verify:
- project state is visible;
- decisions are separated from raw data;
- complex operations are progressive.

## Money confidence

Verify:
- budget state is understandable;
- payments and expenses have clear ownership;
- risky actions require confirmation.

## Trust signals

Verify:
- empty states explain next step;
- errors provide recovery path;
- status changes are understandable.

## Final question

Would a first-time user understand why Renova is an operating system for renovation rather than another task tracker?
