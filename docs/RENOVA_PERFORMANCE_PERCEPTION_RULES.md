# Renova Performance Perception Rules

## Goal

Maintain a feeling of speed and control during daily renovation workflows.

## Perceived performance principles

- Keep important content visible while secondary content loads.
- Avoid sudden layout shifts.
- Preserve user context during navigation and updates.
- Prefer meaningful progress feedback over frozen states.

## Lists and dashboards

Operational screens should:

- show useful information immediately;
- avoid unnecessary loading blocks;
- keep stable structure during refresh.

## Actions

After a user action:

- acknowledge the interaction;
- show the resulting state;
- avoid unclear waiting periods.

## Product principle

A fast product is not only one that computes quickly. It is one where the user always understands what is happening.
