# Renova Interaction Principles

## Purpose

Define interaction rules for the premium polish stage after Clarity A-W.

## Action hierarchy

### Primary

Used for the main business decision on a surface.

Rules:
- one primary action per context;
- visible without scrolling when critical;
- full touch target.

### Secondary

Used for navigation, cancellation, or alternative paths.

Rules:
- outline treatment;
- must not compete with primary.

### Destructive

Used for irreversible operations.

Rules:
- visually distinct from secondary;
- confirmation before execution;
- clear consequence text.

## Information behavior

- Show decision information first.
- Keep metadata secondary.
- Move advanced operations behind sheets or secondary actions.
- Avoid presenting the user with multiple equal choices.

## Mobile ergonomics

- Interactive controls require comfortable touch areas.
- Frequent actions should be reachable with one hand.
- Lists should remain scannable.

## Consistency rule

The same action type must look and behave the same everywhere in Renova.
